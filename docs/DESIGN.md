# CyberStat design system

The Statistical Solver reuses the existing ivory canvas, white surfaces, muted blue accent, sage annotations, amber rejection-region shading, Georgia display headings, system interface fonts, bundled KaTeX, desktop sidebar and mobile navigation.

The main workspace has four numbered steps: statistical method, relevant formula, dynamic inputs, and mathematical/graphical solution. Quick and Detailed modes render the same immutable result through distinct components. Quick uses the engine's explicit substitution and short interpretation; it has no graph, intermediate metrics, step list, assumptions or source discussion. Detailed renders every engine step, method rationale, conditions, intermediate calculation tables, graph and interpretation. Source comparisons appear in Detailed. Units describe the input dimensions without inventing physical measurement labels. Worked Examples and Formula Notebook retain their existing list layouts, content and search/filter behavior. Source grouping identifies provenance and does not expose course-management screens.

Graphs use only observed or mathematically derived values, include labels and legends, expose their underlying data, and identify truncated supports. Small screens stack the workflow and scale chart labels. Long formulas scroll locally. Keyboard focus, reduced motion, validation, empty states, offline status and update prompting remain available.

The solution panel has explicit Quick and Detailed mode classes. Quick uses compact panel and answer padding, shorter gaps between formulas, and content-driven height. Detailed uses comfortable padding and expands with all steps, tables and graphs. The panel aligns to the top of the workspace and does not stretch to match a taller input form. These sizing rules apply to screen layouts and preserve the existing print layout.

All four supplied project details appear in the sidebar and are accessible from the mobile footer. There are no dashboards, progress widgets, lecture explanations, scientific keypad or general equation-solving page.
