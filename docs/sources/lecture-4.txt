            Estimation methods

There are two methods of estimations:
Point estimation:
   A point estimator is an statistic (a function of the random sample). In this method we
estimate the unknown parameter using single value.
    Example:
      𝝁 = 𝟏𝟐𝟎.

      𝝈𝟐 = 𝟏𝟔.


  Interval estimation:
   A confidence interval estimator of a population parameter is a rule for determining
(based on the sample) an interval that is likely to include the parameter.
    Example:
      𝟖𝟎< 𝝁 < 𝟏𝟐𝟎.

     𝟏𝟎< 𝝈𝟐 < 𝟏𝟔.
